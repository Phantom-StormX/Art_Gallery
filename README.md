# Digital art gallery
#### By Izzy !

## Overview
- A classic museum that was made out of python
- consists of 4 different exhibits, each exhibit has at least 4 pieces of art
- Keeps track of how many encounters you have in every exhibit    

## Logic:
  - This game operates based off of loops, variables, conditionals. The main steps can be broken down into the following broad steps:
    - Welcome: Tells the user the instructions and what they are getting into, asks if they want to enter
    - Exhibit entry: asks the user which exhibit they want to enter
    - Art piece: Asks which art piece they want to see in the exhibit they chose
  - Everytime they choose something they will have an option to leave the gallery
## Welcome:
  - The code begins by welcoming the player, telling them how many tickets and encounters they have 
  - Then it asks if they would like to enter
## Exhibits:
  - Computer will ask user which exibhit they would like to see, once they choose and enter a number, it well send the user to the corresponding exhibit
## Pieces:
  - Computer will ask the user which art piece they would like to see in the exhibit they chose, depending on the number, they will see that art piece, then be asked if they would like to go to a different exhibit

## Gallery Ending:
  - The game ends when the user decides to leave


### Challenges and Bugs:
